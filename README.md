# Student Registration Form Using JavaScript

## 📌 About the Project

The Student Registration Form is a simple web development project built using HTML, CSS, and JavaScript. It allows users to register student details, validate form inputs, and manage student records through a dynamic table.

Users can add new students, view registered student details, edit existing records, and delete unwanted records.

## ✨ Features

- **Student Registration:** Add student details through a registration form.
- **Form Validation:** Validate input fields and display appropriate error messages.
- **Student List:** Display registered student details in a table.
- **Edit Student:** Modify and update existing student information.
- **Delete Student:** Remove student records from the list.
- **Dynamic Table:** Update the student list using JavaScript DOM manipulation.
- **Form Reset:** Clear the form fields after successful registration.
- **Responsive Design:** Provide a user-friendly interface across different screen sizes.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 📝 Student Details

The registration form includes the following fields:

- First Name
- Last Name
- Date of Birth
- Gender
- Contact Number

## ⚙️ JavaScript Concepts Used

- Variables and Functions
- Arrays and Objects
- Array Methods (`map()`, `find()`, `filter()`, `push()`, and `splice()`)
- DOM Manipulation
- Event Handling
- Form Validation
- Conditional Statements
- Dynamic HTML Rendering

## 🎯 Project Objective

The objective of this project is to improve front-end development skills by building a student registration system using JavaScript. It demonstrates form validation, CRUD operations, array manipulation, and dynamic table updates without using any JavaScript frameworks.
